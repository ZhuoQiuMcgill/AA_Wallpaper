# AI Constellation Leaderboard — Wallpaper Engine web wallpaper

The Artificial Analysis Intelligence Index drawn as a sky atlas: every ranked model is a star, every model family a constellation. Refreshes from the official Artificial Analysis API on your own key.

## Install
1. Get the built folder (`python3 tools/build.py constellation` → `dist/constellation/`, or a release zip) and either run `python3 tools/deploy.py constellation` or drag its `index.html` onto **Create Wallpaper** in the WE editor. It appears in WE → Installed as "AI Constellation Leaderboard".
2. In the wallpaper's settings panel (right side in WE), paste your **Artificial Analysis API key** (free: artificialanalysis.ai → API key management). Until then the wallpaper shows the bundled snapshot and says `NO API KEY`.
3. Optional: refresh interval (default 4 h), models shown (top 20–60), rank-change window (1/7/30 days), ambient motion, dim stars (ranks N+1..2N), sky ellipse width/height (keep desktop icons clear), background stars, legend.

Data: Artificial Analysis · artificialanalysis.ai (attribution required by the data provider; shown in the footer).
